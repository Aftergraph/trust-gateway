Honest pricing

Three ways to run a governed workforce.

Every tier ships the same core: a zero-dependency gateway (Node core only — no Docker, no Postgres, no Bun), a jailed process island per bot (OS-level sandbox on the roadmap), and a sealed, hash-chained audit trail. What changes is who runs it and how many bots you operate.

Operator solo, self-hosted

Contact

You run the gateway yourself on your own machine. One operator, your own worker bots.

  • Zero-dependency gateway — Node core only, one process
  • Jail per bot: isolated dirs, its own tools, nothing shared
  • Sealed hash-chained audit log, tamper-evident
  • Fail-closed policy engine with human approvals

Team self-hosted, multi-operator

Contact

Same gateway, a real workforce: more bots, more operators, bot-to-bot coordination.

  • Everything in Operator
  • Bot-to-bot groups & handoffs, routines / scheduling
  • Multi-model routing with provider fallback
  • Operator-role approvals over the full bot fleet

Hosted we run it

Contact

We operate the gateway — single-tenant today (multi-tenant foundation on roadmap v3); your bots work in jailed process islands and you keep the audit chain.

  • Everything in Team
  • Single-tenant today — your data and chain stay yours; multi-tenant on the roadmap
  • No ops burden: no Docker, no Postgres, no Bun — we run it
  • Status & seal state visible to you at any time
